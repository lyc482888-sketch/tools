作品介紹與規格書

作品名稱

今天吃什麼？——餐點與飲料抽籤小幫手

目的與使用者

幫助不知道吃什麼、喝什麼的人，依照早餐、午餐、晚餐與餐點類型隨機抽出品項。以一般日常用餐者為對象，支援手機與電腦。

內建清單

212 種餐點與 32 種飲料。包含中西式早餐、中式小吃、美式、韓式、日式、泰式、義式料理，以及蔬菜餐、無澱粉主食與熱湯品項。每個新增餐點均明確設定料理種類、用餐時段、示範參考價和飲食偏好標籤。

操作與功能規格

  1. 選擇「吃什麼」「喝什麼」或「配一套」。餐點及套餐選擇早餐、午餐、晚餐或不限時段；餐點類型包含飯類、麵類、中式、西式、美式、韓式、日式、泰式、義式、其他或不限；另可選餐點預算「銅板美食（70 元以下）」「平價（71–150 元）」「犒賞自己（151 元以上）」。飲食偏好可複選「要有肉、多吃菜、想喝熱湯、不想吃澱粉」，需同時符合所有勾選項目。飲料系列依提供的菜單重整為找好茶、找奶茶、找拿鐵、找新鮮、找冰淇淋；另保留其他飲品供自訂使用。飲料單抽另有預算篩選，留白不限，否則需為 1–10,000 元整數。
  2. 點擊「幫我決定」，小企鵝與籤筒一起搖晃約 2 秒，揭曉時一支籤往上升起，再跳躍揭曉品項與參考價格；偏好減少動態效果的裝置會縮短等待並停用動畫。
  3. 單品模式從符合條件的品項中等機率抽選；套餐模式從符合時段、餐點類型及飲料類型的組合中等機率抽選，餐點符合所選預算級距，套餐飲料另計，不限制合計金額。有替代結果時，排除上次的相同結果。
  4. 套餐可鎖定其中一項，只重新抽另一項。兩項皆鎖定時提示先解鎖；更改模式、條件或品項清單會清除目前結果及鎖定。
  5. 無符合時段或類型的選項時顯示調整建議；飲料單抽不超過所設定的預算。鎖定品項沒有其他搭配時保留結果並提示。
  6. 可新增、編輯、刪除品項。每項包含名稱、類型與參考價格；餐點另設定料理種類、適用時段（可複選）及飲食偏好標籤。「不想吃澱粉」代表品項不含飯、麵、麵包等澱粉主食，依示範組成標記，可自行調整。價格範圍為 1–10,000 元整數，最多 400 項。名稱相同但類型不同可分別儲存；同類型同名品項不重複新增。
  7. 自訂清單使用瀏覽器 localStorage 儲存，並可恢復預設。儲存不可用時提醒使用者，仍可在本次頁面操作。資料只在目前瀏覽器與網址下保存，不跨裝置同步。
  8. 顯示本次頁面最近 5 次結果；重新整理會清除抽籤紀錄，保留已儲存清單。舊版清單升級時會保留自訂品項，替換舊版預設飲料並更新分類；更早的版本另補入新增餐點。新版會自動補入擴充餐點，保留既有自訂與修改；升級儲存後，已刪除的新餐點不會再次補入。若已滿 400 項則不補入。

介面與技術

奶油白、橘色與奶茶色，直接使用提供的棕灰色小企鵝原圖，保留粉紅腮紅、圓肚子與短翅膀，搭配橘黃色籤筒；等待時輕晃，抽籤時一起搖動，揭曉時企鵝跳躍並升起一支籤。單一 index.html 內含 HTML、CSS、JavaScript、內嵌的 PNG 企鵝圖片及 SVG 籤筒，不需外部圖片、網路 API、套件、登入或後端。支援鍵盤操作與減少動態效果設定。

驗收重點

  • 餐點依時段及類型篩選；飯麵與風格可以交叉，例如中式炒飯在「飯類」與「中式」皆可抽到。飲料依類型及預算篩選。
  • 套餐的餐點符合所選時段、類型、預算級距及全部已勾選偏好；鎖定的品項在重抽時維持不變。
  • 只有一個結果時清楚提示；無結果、無效輸入、全鎖定皆有說明。
  • 新增、修改與刪除可更新候選清單；正常儲存後重新整理仍保留。
  • 下載後可直接開啟；上傳 GitHub Pages 後可用網址操作。

GitHub Pages 上線方式

把 index.html 上傳至公開 GitHub 儲存庫的最外層並提交。到 Settings → Pages，將 Source 設為 Deploy from a branch，選取存放檔案的分支（通常為 main）和 / (root)，按 Save。部署完成後開啟 GitHub 顯示的網址。
